# DevOps Learning

Это моя открытая программа обучения DevOps. Здесь я показываю путь, который
прохожу сама, и делюсь материалами, инструментами, функциями и практическими
проектами, которые помогали мне учиться. Это не просто чек-лист тем: цель
репозитория — разобраться, как работают инструменты, и собрать работы, которые
можно добавить в GitHub или портфолио.

## Образование

Мой образовательный путь включает профессиональную подготовку в разработке и
DevOps:

- **Петровский колледж** — специальность «Разработчик»;
- **School 21** — школа программирования от Сбера, направление DevOps;
- **VK Education** — трехмесячный курс по DevOps.

## Как пользоваться репозиторием

Начните с темы в папке [`docs`](docs/): там собраны мои конспекты, объяснения и
ссылки на материалы, которые я смотрела или читала во время обучения. По мере
изучения тем я буду добавлять ссылки и дополнительные материалы для более
глубокого погружения.

После теории переходите в [`labs`](labs/). Здесь находятся реальные задачи,
которые я выполняла, чтобы не только прочитать об инструменте, но и пощупать его
в работе. Лабораторные содержат пошаговые инструкции, готовые файлы и проверки
результата. Их проекты можно повторить, адаптировать под себя и использовать как
часть портфолио или как пример опыта на собеседовании.

Например, в разделе Bash есть лабораторная
[«Свой exporter для Prometheus»](labs/bash/custom-node-exporter/README.md): в
ней создаётся небольшой мониторинг системы на Bash, Nginx и Prometheus.

## Roadmap

Мой текущий маршрут обучения:

```text
Linux → Bash → SQL → Python → Docker → CI/CD → Docker Compose → Мониторинг → Kubernetes
```

Материалы появляются по мере прохождения этого пути. Если вы идёте вместе со
мной, лучше двигаться последовательно: знания из предыдущей темы пригодятся в
следующей.
