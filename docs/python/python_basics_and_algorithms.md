# Основы Python и базовые алгоритмы

## 1. Что такое Python

Python — высокоуровневый язык программирования с динамической типизацией и
акцентом на читаемость кода. Он подходит для автоматизации, веб-разработки,
анализа данных, машинного обучения, тестирования и создания консольных программ.

Язык создал Гвидо ван Россум в конце 1980-х годов. Первая публичная версия
появилась в 1991 году, Python 2 — в 2000 году, а Python 3 — в 2008 году. Сейчас
для новых проектов используется Python 3; поддержка Python 2 завершилась в 2020
году.

Основные достоинства Python:

- простой и выразительный синтаксис;
- большая стандартная библиотека;
- множество сторонних библиотек и активное сообщество;
- работа на Linux, macOS и Windows;
- поддержка процедурного, объектно-ориентированного и функционального стилей;
- автоматическое управление памятью.

### Как выполняется программа

Обычно реализация CPython сначала преобразует исходный код в байткод, а затем
исполняет его на виртуальной машине Python. Этот процесс скрыт от разработчика,
поэтому Python принято называть интерпретируемым языком.

Файл с программой имеет расширение `.py`. Запустить его можно из терминала:

```bash
python3 program.py
```

Python чувствителен к регистру: `name`, `Name` и `NAME` — разные имена. Блоки
кода обозначаются отступами, поэтому одинаковые отступы — часть синтаксиса, а не
только оформление.

## 2. Структура программы

Инструкции верхнего уровня выполняются сверху вниз. Код удобно разбивать на
функции, а запуск программы помещать в `main()`:

```python
def main():
    print("Программа запущена")


if __name__ == "__main__":
    main()
```

Переменная `__name__` равна `"__main__"`, когда файл запущен напрямую. При
импорте этого файла в другой модуль условие ложно, поэтому `main()` не
запустится самостоятельно. Такой шаблон позволяет одновременно использовать файл
и как программу, и как импортируемый модуль.

Виртуальное окружение изолирует зависимости проекта от системного Python и от
других проектов:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3. Переменные и простые типы данных

Переменная появляется при присваивании значения:

```python
count = 10
price = 19.95
title = "Python"
is_ready = True
nothing = None
```

Основные простые типы:

- `int` — целое число;
- `float` — число с плавающей точкой;
- `str` — строка;
- `bool` — логическое значение `True` или `False`;
- `NoneType` — тип специального значения `None`, обозначающего отсутствие
  значения.

Тип определяется во время выполнения и может быть получен функцией `type()`:

```python
value = 42
print(type(value))  # <class 'int'>
```

### Преобразование типов

Для явного преобразования применяются функции `int()`, `float()`, `str()` и
`bool()`:

```python
age = int("25")
temperature = float("18.5")
message = str(100)
```

Если значение нельзя преобразовать, возникает `ValueError`. Например,
`int("abc")` завершится ошибкой.

У `float` возможны небольшие ошибки представления, потому что многие десятичные
дроби нельзя точно записать в двоичной системе. Для финансовых вычислений, где
нужна точная десятичная арифметика, обычно применяют `decimal.Decimal`.

## 4. Операторы

Арифметические операторы:

```python
a + b   # сложение
a - b   # вычитание
a * b   # умножение
a / b   # обычное деление
a // b  # целочисленное деление вниз
a % b   # остаток от деления
a ** b  # возведение в степень
```

Операторы сравнения `==`, `!=`, `<`, `>`, `<=`, `>=` возвращают логическое
значение. Для составных условий используются `and`, `or` и `not`.

`==` сравнивает значения объектов, а `is` — их идентичность. Поэтому с `None`
принято писать `value is None`, но числа и строки обычно сравнивают через `==`.

### Работа с цифрами числа

Последнюю цифру неотрицательного целого числа можно получить через `% 10`, а
удалить её — через `// 10`:

```python
number = 1234
last_digit = number % 10  # 4
number //= 10             # 123
```

Извлекая цифры в цикле, можно собрать число в обратном порядке:

```python
reversed_number = 0

while number > 0:
    reversed_number = reversed_number * 10 + number % 10
    number //= 10
```

Этот приём полезен, когда число нужно анализировать без преобразования в строку.

## 5. Ввод и вывод

`input()` читает одну строку из стандартного потока ввода и всегда возвращает
`str`. Перевод строки в конце не входит в результат:

```python
name = input()
age = int(input())
```

Несколько значений из одной строки часто читают так:

```python
x, y = map(float, input().split())
```

Здесь:

1. `input()` получает строку;
2. `split()` делит её по пробельным символам;
3. `map(float, ...)` преобразует части в числа;
4. распаковка присваивает два результата переменным `x` и `y`.

`print()` выводит значения через пробел и завершает строку переводом строки:

```python
print("Coordinates:", x, y)
print(x, y, sep=", ", end="\n")
```

Для форматирования удобно использовать f-строки:

```python
result = 31.2
print(f"{result:.3f}")  # 31.200
```

Спецификатор `.3f` выводит число с тремя знаками после десятичной точки.

## 6. Управление выполнением программы

### Условные конструкции

```python
if temperature < 0:
    state = "ice"
elif temperature < 100:
    state = "water"
else:
    state = "steam"
```

В условии ложными считаются `False`, `None`, числовой ноль и пустые коллекции.
Остальные значения обычно истинны.

### Цикл `while`

`while` повторяет блок, пока условие истинно:

```python
number = 5

while number > 0:
    print(number)
    number -= 1
```

Такой цикл удобен, когда число повторений заранее неизвестно. Нужно следить,
чтобы условие когда-нибудь стало ложным.

### Цикл `for`

`for` перебирает элементы итерируемого объекта:

```python
for number in range(5):
    print(number)  # 0, 1, 2, 3, 4
```

`range(start, stop, step)` создаёт последовательность целых чисел, не включая
границу `stop`.

Полезные функции для перебора:

```python
for index, value in enumerate(values):
    print(index, value)

for left, right in zip(first, second):
    print(left, right)
```

`enumerate()` даёт индекс и элемент, а `zip()` объединяет элементы нескольких
последовательностей по позициям. `zip()` останавливается вместе с самой короткой
последовательностью.

`break` полностью прекращает цикл, `continue` переходит к следующей итерации.

## 7. Коллекции

### Список

`list` — изменяемая упорядоченная коллекция:

```python
numbers = [10, 20, 30]
numbers.append(40)
numbers[0] = 5
last = numbers[-1]
part = numbers[1:3]
```

Индексация начинается с нуля. Отрицательный индекс отсчитывает элементы с конца.
Срез `sequence[start:stop:step]` не включает позицию `stop`.

Списковое включение компактно создаёт новый список:

```python
squares = [number ** 2 for number in range(6)]
even_squares = [number ** 2 for number in range(6) if number % 2 == 0]
```

### Кортеж

`tuple` — упорядоченная неизменяемая коллекция:

```python
point = (10, 20)
x, y = point
```

Кортежи подходят для небольших наборов связанных значений, состав которых не
должен меняться.

### Множество

`set` хранит только уникальные хешируемые элементы:

```python
numbers = [5, 3, 7, 3, 5]
unique_numbers = set(numbers)
print(len(unique_numbers))  # 3
```

Проверка наличия элемента во множестве в среднем выполняется за `O(1)`, поэтому
множества удобны для удаления повторов и быстрых проверок принадлежности.

### Словарь

`dict` хранит пары «ключ — значение»:

```python
movie = {"title": "Arrival", "year": 2016}
print(movie["title"])
movie["director"] = "Denis Villeneuve"
```

Ключи должны быть хешируемыми: например, строками, числами или кортежами из
хешируемых элементов. Получение значения по ключу в среднем занимает `O(1)`.

Основные способы перебора:

```python
for key in movie:
    print(key)

for key, value in movie.items():
    print(key, value)
```

## 8. Функции

Функция объединяет повторно используемую логику и может принимать аргументы и
возвращать результат:

```python
def dot_product(first, second):
    return sum(a * b for a, b in zip(first, second))
```

`return` завершает функцию и передаёт значение вызывающему коду. Если `return`
не указан, функция возвращает `None`.

Хорошая функция обычно решает одну понятную задачу. Вычисления лучше отделять от
ввода и вывода: тогда функцию проще проверять и повторно использовать.

```python
def calculate_total(prices):
    return sum(prices)


def main():
    prices = list(map(float, input().split()))
    print(calculate_total(prices))
```

Переменная, созданная внутри функции, имеет локальную область видимости. Она не
доступна снаружи функции, если не была возвращена.

## 9. Исключения и проверка входных данных

Исключение сообщает, что во время выполнения возникла необычная ситуация.
Потенциально ошибочную операцию можно обработать конструкцией `try`:

```python
try:
    count = int(input())
    if count <= 0:
        raise ValueError("expected a positive integer")
except ValueError:
    print("Invalid input")
else:
    print("Accepted:", count)
finally:
    print("Finished")
```

- `try` содержит потенциально опасный код;
- `except` обрабатывает указанный тип ошибки;
- `else` выполняется, если исключения не было;
- `finally` выполняется в любом случае;
- `raise` создаёт исключение явно.

Следует перехватывать конкретные типы исключений, а не использовать пустой
`except`. Также не стоит помещать в `try` больше кода, чем действительно может
вызвать ожидаемую ошибку.

Проверка формата и смысла данных — разные этапы. Строка `"-3"` имеет корректный
формат целого числа, но может быть недопустима там, где ожидается натуральное
число.

## 10. Работа с файлами

Контекстный менеджер `with` гарантирует закрытие файла даже при ошибке:

```python
with open("input.txt", encoding="utf-8") as source:
    content = source.read()
```

Основные режимы открытия:

- `"r"` — чтение, используется по умолчанию;
- `"w"` — запись с очисткой существующего файла;
- `"a"` — добавление в конец;
- `"b"` — двоичный режим, например `"rb"`.

Файл можно читать целиком, построчно или как список строк:

```python
with open("input.txt", encoding="utf-8") as source:
    for line in source:
        if line.strip():
            values = list(map(int, line.split()))
```

При работе с текстом кодировку лучше указывать явно. Ошибки файловой системы,
например отсутствие файла, относятся к семейству `OSError`.

## 11. JSON

JSON — текстовый формат обмена структурированными данными. Объект JSON обычно
преобразуется в словарь Python, массив — в список, а строки, числа, логические
значения и `null` — в соответствующие типы Python.

Модуль `json` входит в стандартную библиотеку:

```python
import json

with open("input.json", encoding="utf-8") as source:
    data = json.load(source)

with open("output.json", "w", encoding="utf-8") as target:
    json.dump(data, target, ensure_ascii=False, indent=2)
```

`json.loads()` разбирает строку, а `json.dumps()` создаёт строку. Параметр
`ensure_ascii=False` сохраняет читаемые не-ASCII символы, `indent=2` добавляет
отступы.

Успешный разбор JSON ещё не означает, что данные подходят программе. После
разбора нужно проверить структуру: ожидаемые ключи, типы значений, обязательные
поля и ограничения предметной области. Ошибка синтаксиса JSON имеет тип
`json.JSONDecodeError`.

При проверке целых чисел важно помнить, что `bool` является подклассом `int`:

```python
isinstance(True, int)  # True
```

Если логические значения недопустимы, это условие проверяют отдельно.

## 12. Матрицы и обход клеток

Матрицу удобно представлять списком списков:

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
]

value = matrix[1][2]  # 6
```

Количество строк равно `len(matrix)`, а количество столбцов прямоугольной
непустой матрицы — `len(matrix[0])`.

Для перебора всех клеток используют вложенные циклы:

```python
for row in range(len(matrix)):
    for column in range(len(matrix[row])):
        print(matrix[row][column])
```

Соседей по вертикали и горизонтали можно описать смещениями:

```python
directions = ((-1, 0), (1, 0), (0, -1), (0, 1))

for delta_row, delta_column in directions:
    new_row = row + delta_row
    new_column = column + delta_column
```

Перед обращением к клетке обязательно проверяют границы:

```python
if 0 <= new_row < height and 0 <= new_column < width:
    ...
```

### Поиск связных компонентов

Связная компонента — группа клеток, между которыми можно перемещаться по
разрешённым направлениям. Её находят поиском в глубину (DFS) или ширину (BFS).
Итеративный DFS использует стек:

```python
stack = [(start_row, start_column)]
visited = {(start_row, start_column)}

while stack:
    row, column = stack.pop()

    for delta_row, delta_column in directions:
        neighbour = (row + delta_row, column + delta_column)
        new_row, new_column = neighbour

        if (
            0 <= new_row < height
            and 0 <= new_column < width
            and matrix[new_row][new_column] == 1
            and neighbour not in visited
        ):
            visited.add(neighbour)
            stack.append(neighbour)
```

Клетку отмечают посещённой при добавлении в стек, чтобы не добавить её повторно.
Если каждая клетка и каждое соседство обрабатываются ограниченное число раз,
сложность обхода матрицы составляет `O(rows * columns)`.

Форму компоненты можно исследовать по её ограничивающему прямоугольнику. Для
полностью заполненного квадрата ширина и высота равны, а число клеток равно
`width * height`. Такая проверка корректна только при заранее известных
ограничениях на возможные фигуры.

## 13. Полезные алгоритмические схемы

### Скалярное произведение

Скалярное произведение двух векторов одинаковой длины — сумма произведений
соответствующих координат:

\[ a \cdot b = a_1b_1 + a_2b_2 + \ldots + a_nb_n. \]

В Python эту формулу можно выразить через `zip()` и `sum()`:

```python
result = sum(a * b for a, b in zip(first, second))
```

Перед вычислением в прикладной программе нужно проверить равенство длин, потому
что `zip()` молча отбросит лишние элементы более длинной последовательности.
Сложность алгоритма — `O(n)`.

### Построение следующей строки треугольника Паскаля

Каждая строка треугольника начинается и заканчивается единицей. Внутренний
элемент равен сумме двух соседних элементов предыдущей строки:

```python
current = [1]

for _ in range(number_of_rows):
    print(*current)
    current = (
        [1]
        + [current[index] + current[index + 1]
           for index in range(len(current) - 1)]
        + [1]
    )
```

Если построить `n` строк, общее число вычисленных элементов пропорционально
`n²`, поэтому временная сложность равна `O(n²)`.

### Слияние отсортированных списков

Два уже отсортированных списка не нужно соединять и сортировать заново. Можно
поставить по указателю в начало каждого списка, сравнивать текущие элементы и
переносить меньший в результат:

```python
def merge(first, second):
    result = []
    left = right = 0

    while left < len(first) and right < len(second):
        if first[left] <= second[right]:
            result.append(first[left])
            left += 1
        else:
            result.append(second[right])
            right += 1

    return result + first[left:] + second[right:]
```

Для списков длины `n` и `m` время работы равно `O(n + m)`. Это та же операция
слияния, которая используется в сортировке слиянием.

### Динамическое программирование на сетке

Если по прямоугольному полю разрешено двигаться только вправо и вниз, лучший
результат для клетки зависит от лучших результатов для клетки сверху и клетки
слева:

\[ dp[r][c] = value[r][c] + \max(dp[r - 1][c], dp[r][c - 1]). \]

Полную таблицу хранить необязательно. Если строки обрабатываются сверху вниз,
достаточно одномерного массива длиной, равной числу столбцов:

```python
best = [0] * columns

for row in range(rows):
    values = list(map(int, input().split()))

    for column, value in enumerate(values):
        from_above = best[column]
        from_left = best[column - 1] if column > 0 else 0
        previous = max(from_above, from_left) if row > 0 or column > 0 else 0
        best[column] = value + previous
```

Время работы — `O(rows * columns)`, дополнительная память — `O(columns)`.
Начальную клетку и границы нужно обрабатывать отдельно. Значение `0` как
несуществующий путь безопасно только тогда, когда веса клеток неотрицательны.

### Многочлен и схема Горнера

Пусть коэффициенты многочлена записаны от старшей степени к младшей:

\[ P(x) = a_nx^n + a_{n-1}x^{n-1} + \ldots + a_1x + a_0. \]

Его производная:

\[ P'(x) = na_nx^{n-1} + (n-1)a_{n-1}x^{n-2} + \ldots + a_1. \]

Значение производной в точке можно вычислить за `O(n)` по схеме Горнера, не
возводя точку в каждую степень отдельно:

```python
derivative = 0.0

for index, coefficient in enumerate(coefficients[:-1]):
    power = degree - index
    derivative = derivative * point + coefficient * power
```

Свободный коэффициент не входит в вычисление, потому что его производная равна
нулю.

### Поиск лучшей пары

Когда требуется выбрать два элемента, простой способ — перебрать все пары:

```python
best = None

for first in range(len(items)):
    for second in range(first + 1, len(items)):
        if pair_is_valid(items[first], items[second]):
            candidate = pair_cost(items[first], items[second])
            if best is None or candidate < best:
                best = candidate
```

Начало второго цикла с `first + 1` исключает сравнение элемента с самим собой и
повторный просмотр пары в обратном порядке. Для `n` элементов сложность такого
решения — `O(n²)`.

При больших объёмах данных алгоритм часто ускоряют словарём: сохраняют уже
встреченные элементы по признаку, необходимому для поиска дополнения. Тогда во
многих задачах время можно уменьшить до `O(n)` ценой дополнительной памяти.

## 14. Самостоятельный разбор строки с числом

Ручной разбор числовой строки полезен для понимания того, как устроены парсеры.
Типичный алгоритм для простой десятичной записи:

1. удалить пробелы по краям;
2. определить знак по первому символу;
3. проверить, что десятичная точка встречается не более одного раза;
4. убедиться, что остальные символы — цифры;
5. накопить целую часть по правилу `result = result * 10 + digit`;
6. добавить дробные цифры с весами `0.1`, `0.01`, `0.001` и так далее;
7. применить знак.

Преобразовать символ цифры в число можно через разность кодов символов:

```python
digit_value = ord(character) - ord("0")
```

Такой учебный парсер обычно поддерживает только заранее оговорённый формат. Для
полного аналога `float()` пришлось бы также учесть экспоненциальную запись,
специальные значения, пробельные символы и другие детали грамматики.

## 15. Оценка сложности

Оценка сложности показывает, как растут затраты при увеличении входных данных:

- `O(1)` — время не зависит от размера входа;
- `O(n)` — один полный проход по коллекции;
- `O(n²)` — перебор всех пар или двойной цикл по двум измерениям размера `n`;
- `O(rows * columns)` — обход каждой клетки матрицы;
- `O(n + m)` — совместный проход по двум коллекциям.

Кроме времени учитывают дополнительную память. Например, множество уникальных
значений требует `O(n)` памяти, а динамическое программирование на сетке можно
сжать с `O(rows * columns)` до `O(columns)`.

## 16. Практические принципы хорошего кода

- Давайте переменным и функциям имена, раскрывающие их назначение.
- Разделяйте чтение данных, проверку, вычисление и вывод результата.
- Не изменяйте входные данные без необходимости.
- Проверяйте не только тип, но и допустимый диапазон и структуру данных.
- Используйте `with` для файлов и перехватывайте конкретные исключения.
- Учитывайте пустой ввод, граничные значения, одну строку или один элемент.
- Сначала добивайтесь корректности, затем оценивайте сложность и оптимизируйте.
- Для нетривиальной логики пишите небольшие тесты с обычными и граничными
  случаями.

Этот набор тем формирует базу для дальнейшего изучения модулей, тестирования,
объектно-ориентированного программирования, алгоритмов и разработки прикладных
программ на Python.
