# PostgreSQL. Агрегатные функции, группировка и аналитические запросы

## Что такое аналитические запросы

В большинстве информационных систем данные сначала накапливаются в виде
отдельных записей (транзакций, заказов, посещений, платежей), а затем
анализируются для получения полезной информации.

Например, бизнес редко интересует каждый отдельный заказ. Гораздо важнее узнать:

- сколько заказов было сделано;
- какая пиццерия самая популярная;
- средняя стоимость заказа;
- сколько клиентов посетило ресторан;
- какие адреса наиболее активны.

Такие запросы называют **аналитическими**.

---

# OLTP и OLAP

## OLTP (Online Transaction Processing)

OLTP предназначен для хранения и обработки оперативных данных.

Примеры:

- оформление заказа;
- регистрация пользователя;
- добавление товара;
- изменение информации.

Особенности:

- большое количество небольших операций;
- высокая скорость записи;
- работа с отдельными строками.

---

## OLAP (Online Analytical Processing)

OLAP используется для анализа уже накопленных данных.

Примеры:

- расчёт прибыли;
- анализ продаж;
- поиск самых популярных товаров;
- построение отчётов.

Особенности:

- работа с большими объёмами данных;
- использование агрегатных функций;
- сложные аналитические запросы.

---

# Агрегатные функции

Агрегатные функции выполняют вычисления сразу над группой строк.

Основные агрегатные функции:

| Функция   | Назначение               |
| --------- | ------------------------ |
| `COUNT()` | подсчёт количества строк |
| `SUM()`   | сумма значений           |
| `AVG()`   | среднее значение         |
| `MIN()`   | минимальное значение     |
| `MAX()`   | максимальное значение    |

---

# COUNT()

Подсчитывает количество строк.

Пример:

```sql
SELECT COUNT(*)
FROM person_order;
```

Количество заказов каждого пользователя:

```sql
SELECT
    person_id,
    COUNT(*) AS count_of_orders
FROM person_order
GROUP BY person_id;
```

---

# GROUP BY

`GROUP BY` объединяет строки с одинаковыми значениями и позволяет выполнять
агрегатные функции для каждой группы.

Например:

```sql
SELECT
    person_id,
    COUNT(*)
FROM person_visits
GROUP BY person_id;
```

Получаем количество посещений каждого пользователя.

Правило:

> Все столбцы в `SELECT`, которые не являются агрегатными функциями, должны
> присутствовать в `GROUP BY`.

Например:

```sql
SELECT
    p.id,
    p.name,
    COUNT(*)
FROM person p
JOIN person_visits pv
ON pv.person_id = p.id
GROUP BY p.id, p.name;
```

---

# ORDER BY после группировки

После выполнения группировки результаты можно отсортировать.

Например:

```sql
ORDER BY
    count_of_visits DESC,
    person_id ASC;
```

Сначала записи сортируются по количеству посещений (по убыванию), затем — по
идентификатору пользователя.

---

# LIMIT

`LIMIT` ограничивает количество возвращаемых строк.

Например:

```sql
LIMIT 5;
```

Используется для получения:

- топ-10 клиентов;
- трёх самых популярных ресторанов;
- первых пяти записей.

---

# Подзапросы

Подзапрос позволяет использовать результат одного запроса в другом.

Например:

```sql
SELECT *
FROM (
    SELECT ...
) AS top_visitors;
```

Во внутреннем запросе вычисляются данные, а внешний запрос может дополнительно
их сортировать, фильтровать или объединять.

---

# UNION ALL

`UNION ALL` объединяет результаты нескольких запросов.

```sql
SELECT ...
UNION ALL
SELECT ...
```

Особенности:

- сохраняет все строки;
- не удаляет дубликаты;
- работает быстрее, чем `UNION`.

Используется, когда необходимо объединить результаты разных выборок.

Например:

- статистику заказов;
- статистику посещений.

---

# Общие табличные выражения (CTE)

CTE создаются с помощью оператора `WITH`.

Пример:

```sql
WITH visits AS (
    SELECT ...
)
SELECT ...
```

Преимущества:

- запрос становится более читаемым;
- можно разбить сложную логику на части;
- одно выражение можно использовать несколько раз.

Например:

```sql
WITH visits AS (...),
orders AS (...)
SELECT ...
```

---

# FULL JOIN

`FULL JOIN` объединяет данные из обеих таблиц.

Если запись отсутствует в одной таблице, PostgreSQL всё равно вернёт строку,
заполнив отсутствующие значения `NULL`.

Например:

```sql
FULL JOIN orders
ON ...
```

Используется, когда необходимо сохранить все данные из обеих таблиц.

---

# COALESCE()

Функция

```sql
COALESCE()
```

возвращает первое значение, которое не равно `NULL`.

Например:

```sql
COALESCE(count_of_visits, 0)
```

Если посещений нет, вместо `NULL` будет подставлено `0`.

Можно использовать сразу несколько аргументов:

```sql
COALESCE(a, b, c, 0)
```

---

# HAVING

`HAVING` фильтрует уже сформированные группы.

В отличие от `WHERE`, он работает после выполнения `GROUP BY`.

Например:

```sql
SELECT
    person_id,
    COUNT(*)
FROM person_visits
GROUP BY person_id
HAVING COUNT(*) > 3;
```

Получаем только пользователей, посетивших ресторан более трёх раз.

### Отличие WHERE и HAVING

`WHERE`

- фильтрует строки **до** группировки.

```sql
WHERE age > 18
```

`HAVING`

- фильтрует группы **после** группировки.

```sql
HAVING COUNT(*) > 5
```

---

# DISTINCT

Удаляет повторяющиеся строки.

Например:

```sql
SELECT DISTINCT name
FROM person;
```

Если пользователь сделал несколько заказов, его имя всё равно будет показано
только один раз.

---

# AVG()

Вычисляет среднее значение.

Например:

```sql
AVG(price)
```

Средняя стоимость заказов по каждой пиццерии:

```sql
SELECT
    p.name,
    AVG(m.price)
FROM ...
GROUP BY p.name;
```

---

# ROUND()

Округляет число.

Например:

```sql
ROUND(AVG(price), 2)
```

Результат будет содержать два знака после запятой.

Также можно округлять до любого количества знаков:

```sql
ROUND(value, 4)
```

---

# MAX() и MIN()

Позволяют определить максимальное и минимальное значение.

Например:

```sql
MAX(price)
MIN(price)
```

Используются для поиска:

- самой дорогой пиццы;
- самой дешёвой пиццы;
- максимального возраста;
- минимального рейтинга.

---

# Вычисление нескольких агрегатов одновременно

В одном запросе можно использовать сразу несколько агрегатных функций.

Например:

```sql
SELECT
    COUNT(*),
    AVG(price),
    MAX(price),
    MIN(price)
FROM ...
```

Это позволяет получить полную статистику за один проход по данным.

---

# Глобальные агрегаты

Если не использовать `GROUP BY`, агрегатная функция вычисляется сразу по всей
таблице.

Например:

```sql
SELECT AVG(rating)
FROM pizzeria;
```

Результат — средний рейтинг всех пиццерий.

---

# Группировка по нескольким столбцам

Можно объединять строки сразу по нескольким полям.

Например:

```sql
GROUP BY
    address,
    pizzeria_name;
```

В этом случае каждая группа определяется уникальной комбинацией адреса и
пиццерии.

---

# Арифметические операции в SQL

SQL позволяет выполнять вычисления непосредственно в запросе.

Например:

```sql
MAX(age) - MIN(age)
```

или

```sql
SUM(price) / COUNT(*)
```

Можно комбинировать арифметические операции с агрегатными функциями.

---

# Приведение типов

Иногда необходимо преобразовать один тип данных в другой.

Например:

```sql
MIN(age)::numeric
```

или

```sql
CAST(age AS numeric)
```

Это особенно важно при делении, чтобы избежать потери дробной части.

---

# Логические выражения

SQL умеет вычислять логические выражения.

Например:

```sql
formula > average
```

Результат:

- `TRUE`;
- `FALSE`.

Такие вычисления удобно использовать в аналитических отчётах.

# Практические рекомендации

- Используйте агрегатные функции для построения статистики и отчётов.
- После применения агрегатных функций группируйте данные с помощью `GROUP BY`.
- Для фильтрации агрегированных результатов используйте `HAVING`, а не `WHERE`.
- Если необходимо заменить `NULL`, применяйте `COALESCE()`.
- Используйте `WITH` (CTE), чтобы сделать сложные запросы более понятными и
  поддерживаемыми.
- Для объединения независимых выборок используйте `UNION ALL`, если сохранение
  дубликатов допустимо.
- Округляйте результаты вычислений функцией `ROUND()`, чтобы сделать отчёты
  более удобными для чтения.
- Используйте `DISTINCT`, когда требуется получить только уникальные значения.

# Итоги

После изучения темы необходимо понимать:

- чем отличаются OLTP и OLAP;
- как использовать агрегатные функции `COUNT`, `SUM`, `AVG`, `MIN` и `MAX`;
- как выполнять группировку данных с помощью `GROUP BY`;
- чем отличаются `WHERE` и `HAVING`;
- как использовать `DISTINCT` для получения уникальных значений;
- как ограничивать количество результатов с помощью `LIMIT`;
- как объединять результаты нескольких запросов через `UNION ALL`;
- как применять общие табличные выражения (`WITH`) для упрощения сложных
  запросов;
- как использовать `FULL JOIN` и `COALESCE()` при объединении данных;
- как выполнять вычисления и округление результатов непосредственно в
  SQL-запросах;
- как строить аналитические отчёты на основе данных из нескольких таблиц.
